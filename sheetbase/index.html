Google スプレッドシートをデータベースにするサーバーです。シート 1 枚がテーブル 1 つ。Firebase や Supabase のように、ブラウザから読み書き・ログインができます。

はじめかた

  1. 新しい Google スプレッドシートを作り、拡張機能 → Apps Script を開く。
  2. はじめから入っているコードを消して、サーバーのコードを貼り付ける。
    ダウンロード
  3. 保存する（Ctrl+S ／ ⌘+S）。
  4. デプロイ → 新しいデプロイ。歯車から ウェブアプリ を選び、「実行するユーザー：自分」「アクセスできるユーザー：全員」にしてデプロイ。はじめの 1 回は Google の許可画面が出ます（「詳細」→「（安全ではないページ）に移動」→「許可」）。
  5. 出てきた URL（…/exec）を下の「ためす」に入れる。

学校や会社の Google アカウント（Google Workspace）では、「アクセスできるユーザー」に「全員」が出ず「（組織名）内の全員」しか選べないことがあります。その設定だとブラウザからつながりません（CORS エラーになります）。個人の Gmail アカウントで作ってください。

つながらないときは、URL をシークレットウィンドウで直接開いてみてください。{"data":{"ok":true,…}} と出れば設定は合っています。Google のログイン画面が出るなら「アクセスできるユーザー」が「全員」になっていません。

管理キーが要るときは、スプレッドシートを開き直すとメニューに出る Sheetbase → 管理キーを表示 で見られます。

コードやルールを変えたあとは、デプロイを管理 → 編集 → 新バージョン でデプロイし直すと反映されます。

つかいかた

  1. 下の「ためす」に URL を入れて つなぐ → 新しく登録 → 足す。スプレッドシートにシート「todos」ができて、行が入るのを見てみてください。
  2. 見本のアプリ ひとこと掲示板 を開く（「ためす」でつないだ URL をそのまま使います）。書きこむとシート「posts」に入ります。
  3. 自分のアプリを作るときは、example.html をダウンロードして、中の URL = '' に自分の URL を入れ、書きかえていきます。sheetbase.js は次の 1 行で読みこめます。 
    <script src="https://tools-three-bay-66.vercel.app/sheetbase/sheetbase.js"></script>

書き方のまとめ：

<script src="sheetbase.js"></script>
<script>
const sb = Sheetbase.createClient('https://script.google.com/macros/s/XXXX/exec');

// ログイン
await sb.auth.signUp({ email: 'me@example.com', password: 'password123' });
await sb.auth.signIn({ email: 'me@example.com', password: 'password123' });

// 足す（シート「todos」が無ければ自動でできる）
await sb.from('todos').insert({ title: '牛乳を買う', done: false });

// 読む
const { data, error } = await sb.from('todos')
  .select('id,title')
  .eq('done', false)
  .order('createdAt', { ascending: false })
  .limit(10);

// 書きかえる・消す
await sb.from('todos').update({ done: true }).eq('id', data[0].id);
await sb.from('todos').delete().eq('id', data[0].id);

// 5 秒ごとに見に行き、変わったら呼ばれる
const stop = sb.from('todos').select().subscribe(({ data }) => render(data));
</script>

だれが読み書きできるかは Code.gs の RULES で決めます（public・auth・owner・admin）。くわしくは README に。
